# Public / Private Boundary

## Safe to publish

- high-level thesis;
- neutral schemas;
- synthetic demo;
- high-level governance philosophy;
- public threat model;
- non-proprietary UI;
- generic integration interfaces.

## Keep private

- collateral eligibility formulas;
- haircut algorithms;
- liquidation parameters;
- routing optimization;
- pricing and fee model;
- treasury policy;
- exact Sharia product structuring;
- regulator/counsel work product;
- investor CRM;
- strategic partner pipeline;
- unpublished product roadmap;
- market-entry sequencing;
- live counterparty exposure;
- security architecture details;
- production keys/secrets;
- proprietary data sets;
- model weights/prompts where strategically sensitive.

## Rule

If publishing a detail would let a competitor reproduce the economic engine without needing the founding team, it belongs in the private repository.
